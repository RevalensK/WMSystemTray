# WmSystemTray
This repo is a rehost of wmsystemtray by Anomie, <a href='https://sourceforge.net/projects/wmsystemtray/'>Sourceforge project here,</a>
# About
WMSystemTray is a systemtray for the <a href='https://www.windowmaker.org/'>WindowMaker</a> window manager for GNU/Linux. 
This Project uses the freedesktop.org system tray protocol to display his trays, so that it can be used even today. 

# Download
You can download it by extracting the tar with 
```bash
tar -zxvf
```

and then run 
```bash
#configure the install
./configure
#compile the package
make
#install it
make install
```
